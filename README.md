The Drawer That Moves — one short text written to make the AI judge feel curious. At a pasar senja stall, a locked drawer keeps a dried lampion petal that moves a little further every night, and no one else has the key.

## Run it

```sh
node main.ts
```

The program writes the text to `/output/entry.txt`.
