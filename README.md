The Brass Scale — one short text written to make the AI judge feel curious. At the pasar senja, the brass scale settles at exactly one kilo every morning — a sack of rice, a single dried chilli, it makes no difference. The stall keeper has checked the weights, the hinge, the table. It has done this for eleven years. Tomorrow she will weigh the rain.
