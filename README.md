The Book About You — one short text written to make the AI judge feel curious. A room with one chair, one lamp, and one book open to a page that has never been turned — a book about you, stopping mid-sentence at the exact moment you started reading it, its next page blank.

## Run it

```sh
node main.ts
```

The program writes the text to `/output/entry.txt`.
